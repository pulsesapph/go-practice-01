# Практическая работа № 1. Знакомство с Go

Курс «Бэкенд-разработка на языке Go».

## Окружение

- Операционная система: Windows 11.
- Версия Go: go version go1.27.2 windows/amd64
- Редактор: Visual Studio Code.

## Выполнено

Опишите только то, что действительно выполнено. После каждого следующего задания обновляйте этот раздел.

## Запуск первой программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```text
go run .
```

## Проверка сборки и оформления

```text
go fmt ./...
go build ./...
```

## Дополнительные программы

Карточка

```text
go run ./cmd/card
```

Конвертер

```text
go run ./cmd/time-converter
```

## Проверенные данные

Карточка: изменены имя участника и продолжительность. В выводе соответствующие данные изменились.

Конвертер: Входные данные - семь наборов из условия задачи. В выводе результаты совпадают с ответами, приведёнными в таблице из условия задания.
